Classic WW Points Tracker v5

Install:
1. Back up your current Common Foods CSV and Food Diary CSV from the app first.
2. Extract this ZIP.
3. Upload ALL files in this folder to the root of your existing GitHub Pages repository, replacing the files with the same names.
4. Commit the changes.
5. Open https://kanoks23.github.io/classic-ww-points/?v=5

This version keeps the existing localStorage key (classicWWPoints.v1) so the app continues using data already saved in this browser. It does not sync data between devices. Keep your CSV backups.

Files: index.html, sw.js, manifest.webmanifest, food_database.csv, icon-192.png, icon-512.png, README.txt
