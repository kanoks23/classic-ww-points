Classic WW Points Tracker v5.1

Changes:
- Food Diary is now the first card on the Diary page.
- Added an Add Food button in the Food Diary header. It opens the Foods tab and scrolls to the Add a Food form.
- Save as Meal now opens a picker of individual diary entries grouped by meal. Select only the foods to include, name the meal, and save.

Install:
1. Back up Food Diary and Common Foods CSV files.
2. Upload all files in this folder to the root of your existing GitHub Pages repository, replacing files with matching names.
3. Commit the changes.
4. Open https://kanoks23.github.io/classic-ww-points/?v=5.1

The app retains the existing localStorage key classicWWPoints.v1.
